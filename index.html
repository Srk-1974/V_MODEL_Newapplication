Frequently Asked Questions (FAQ)

Q: Can I use V-PATH.AGENT with any AI Model? +
Yes! Context Bundles are machine-readable and model-agnostic. They work with Gemini 3.7 / 3.6, Antigravity, Claude 3.7, GPT-4o, Cursor, GitHub Copilot, and local LLMs (Llama 3 / Ollama).
Q: What does "Vertex: Code" mean? +
In the V-Model diagram, the "Vertex" is the bottom tip of the V. It represents actual source code (C/C++/Rust) where top-down planning transitions into bottom-up verification. In V-PATH, the Vertex is highlighted in crimson red (#D93838).

Out-of-the-box support for IEC 62304 (Medical Class A/B/C), ISO 26262 (Automotive ASIL A-D), DO-178C (Aerospace DAL A-E), and ISO 14971 Risk Management.
